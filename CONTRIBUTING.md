# Contribuir a LANXIS

Abra un Issue con plataforma, versión, pasos para reproducir y evidencia sin datos privados. Para cambios de código, use ramas `feature/...` o `update/...`, agregue pruebas relevantes y ejecute `flutter analyze` y `flutter test`. No incorpore resultados simulados como mediciones reales. Documente definiciones de métricas, supuestos y límites de hardware.

Las contribuciones aceptadas se distribuirán con la licencia del proyecto; las bibliotecas de terceros conservan sus propias licencias. No incluya credenciales ni contraseñas de redes.
